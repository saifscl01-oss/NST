# NST — 12-Month Monthly Data

**Compiled:** Sept 4, 2026, live pulls from Spotify for Artists (custom monthly date ranges, Songs → Overview → Filters, per track).
**Purpose:** Raw monthly time series behind `halos-momentum-analysis.html`. Where the earlier `nst-sauvachi-raw-data-handoff.md` gave only two-point (28-day vs. prior-28-day) snapshots, this adds actual month-by-month granularity for three tracks across up to 12 months, to support trend/lag analysis instead of single-comparison reads.

**Scope note (2026-09-28 reorg):** This file now holds NST-attributed tracks only (own-profile and joint releases pulled from NST's own Spotify for Artists profile). sauvachi's solo catalog (money gene, yours, Again EP) moved to `../sauvachi/sauvachi-12month-monthly-data.md` as part of splitting NST vs. sauvachi data collation into separate folders. See `../collation-log/collation-log.md` for the full history of every collation exercise, on both sides, going forward.

Note: Feb 2026 for CARBON was reconstructed by subtraction from two cumulative pulls (Jan+Feb minus Jan) for streams/saves/playlist adds, then independently re-pulled as a standalone month to confirm the derived figures matched exactly (they did) — see the analysis file for the anomaly this caused during collection.
